# EXIF Reader

Cross-platform desktop app to parse and display EXIF headers from images.

![Screenshot of EXIF Reader](https://raw.githubusercontent.com/rphillips-nz/exif-reader/main/raw/screenshot.png)

***

## Features

- 📄 Supports multiple file types (JPG/JPEG, PNG, TIF/TIFF, HEIC)
- 🕶 Dark mode support for macOS
- 💧 Drag and drop files
- 🚀 Fast parsing and UI

## Development

Build:

```sh
cargo build
```

Run:

```sh
cargo run
```

New versions are built and released via GitHub Actions.
